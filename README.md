# miniproject_ijazah

cara menjalankan proses pembacaan ijazah/OCR 

Jalankan perintah:
python -m venv .venv

Aktifkan virtual environment:
.venv\Scripts\activate

Jika menggunakan perintah py untuk menjalankan Python, gunakan:
py -m venv .venv

install library 
python -m pip install --upgrade pip
pip install -r requirements.txt

Tunggu sampai seluruh library selesai diinstal.

Jika tidak ada requirements.txt, instal library sesuai kebutuhan dan impor yang digunakan dalam kode proyek.

Jalankan perintah:

streamlit run app.py

Buka Aplikasi di Browser
http://localhost:8501
